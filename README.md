# 🏛️ 정밀 부가가치세 계산기 & 전표 대사 대시보드 (VAT Calculator Pro)

대한민국 세법(부가가치세법 및 국세징수법 제74조)의 단수처리 규정을 준수하며, 대량의 엑셀/CSV 전표를 드래그 앤 드롭으로 대사(오차 검증) 및 시각화하는 엔터프라이즈급 순수 프론트엔드 웹 애플리케이션입니다.

Anthropic의 따뜻한 에디토리얼 디자인 시스템(Warm-Canvas Editorial Design)을 기반으로 제작되었습니다.

---

## ✨ 핵심 기능

### 1. 정밀 부가가치세 연산 엔진
- **양방향 실시간 산출**:
  - 공급가액(단가/과세표준) 입력 시 부가세액(10%) 및 공급대가 자동 산출
  - 공급대가(실결제액) 입력 시 공급가액과 부가세액 정밀 역산
- **세법 표준 단수처리 4종 지원**:
  - **반올림 (Round)**: 세금계산서 표준
  - **원단위 절사 (Floor)**: 보수적 회계 기준
  - **국세징수법 제74조 10원 미만 절사**: 국가 징수 규정(1원 단위 버림)
  - **올림 (Ceil)**
- **과세 유형별 대응**:
  - 일반과세 (10%)
  - 영세율 (0%)
  - 면세 (비과세 0원)
  - 간이과세 (소매 15%, 제조 20%, 건설 30%, 서비스 40% 부가가치율)
- **실무 특수 예외 처리**:
  - 비과세 봉사료 분리 산출
  - 매입세액 불공제 항목 비용 산입 안내
  - 마이너스(±) 수정세금계산서 및 반품/환불 처리
  - 실시간 한글 금액 변환 표기 (예: `1,234,500원` → `일백이십삼만사천오백 원`)
  - 결과 텍스트 및 엑셀 붙여넣기용 표 서식(TSV) 원클릭 복사

### 2. 📊 엑셀/CSV 일괄 대사 (Audit) & 재계산
- **드래그 앤 드롭 업로드**: `.xlsx`, `.xls`, `.csv` 파일을 서버 전송 없이 브라우저 내에서 안전하게 즉시 파싱
- **열(Column) 스마트 자동 매핑**: 품목명, 공급가액, 세액, 합계 열 자동 감지
- **1원 단위 정밀 대사 검증**:
  - 엑셀 기재 금액 vs 선택된 단수처리 기준 계산 금액 교차 검증
  - `정상 일치`, `세액 불일치`, `합계 불일치` 실시간 감지 및 오차액 표기
  - `불일치/오차만 보기` 필터링 지원
- **일괄 자동 재계산**:
  - 공급가액 기준 세액·합계 일괄 재계산
  - 합계금액(결제액) 기준 공급가액·세액 일괄 역산
- **결과 엑셀 내보내기**: 대사 상태와 오차 내역이 포함된 `.xlsx` 파일 다운로드

### 3. 📈 통계·시각화 대시보드
- 대량 전표 데이터 로드 시 실시간 차트 렌더링 (Chart.js)
  - **상단 핵심 KPI**: 총 전표 건수, 총 공급가액, 총 부가세액, 총 공급대가, 건당 평균액, 대사 오차율
  - **월별 추이**: 공급가액(Bar) & 부가세액(Line) 복합 차트
  - **거래처 TOP 10**: 공급가액 기준 상위 8개 거래처 수평 바 차트
  - **품목별 비중**: 주요 계정/품목별 지출 도넛 차트
  - **대사 정합성 비율**: 정상 vs 오차 비율 도넛 차트
- **5,000건 현실 전표 샘플 데이터** 원클릭 로드 및 벤치마크 지원

### 4. 🎨 Claude 에디토리얼 디자인 시스템
- **Warm Cream Canvas (`#faf9f5`)**: 눈이 편안한 따뜻한 틴티드 크림 배경
- **Signature Warm Coral (`#cc785c`)**: 앤트로픽 고유의 코랄 액센트 및 방사형 4-Spoke Spike 심볼
- **Dark Navy Product Chrome (`#181715`)**: 세금계산서 프리뷰 및 명세서 카드에 코드 에디터 감성의 다크 서피스 적용
- **문학적 타이포그래피**: Cormorant Garamond (Serif 400), Inter (Sans), JetBrains Mono (Code)

## 🚀 빠른 시작

별도의 Node.js 빌드나 백엔드 서버 구동 없이, 브라우저에서 바로 열어 사용할 수 있는 순수 프론트엔드 프로젝트입니다.

```bash
# 저장소 복제
git clone https://github.com/shoman2/vat-calculator.git
cd vat-calculator

# 브라우저에서 바로 실행 (Mac 기준)
open index.html
```
